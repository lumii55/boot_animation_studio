Tips for Beginners

  • Companion Module: The "Connect to Phone" feature requires our optional root module. The site works 100% perfectly without it, but for direct phone integration, download the module from our GitHub Repository.
  • Important (Samsung): Because .qmg is a closed format, this site doesn't generate animations for stock Samsung. You MUST be on a Custom ROM/GSI! Root access is required.
  • Size matters: Avoid files larger than 20MB. Heavy files can cause Android to stutter or even cause bootloops.
  • Screen aspect: Use Framing to choose how videos with a different aspect ratio are cropped, fitted or stretched.
